# Week 1

Create synthetic data, fit a the linearised model, and produce a log-log plot.

## Requirements

- Python 3
- NumPy
- Matplotlib

Install the required packages with

```bash
pip install numpy matplotlib
```

## Running

From this directory, run

```bash
python blast_wave.py
```

The script will:
- generate synthetic data,
- fit the linearised model,
- print the recovered slope and energy,
- save the figure as `figure.png`.
