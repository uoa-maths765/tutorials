The equilibria for $(\theta,v)$
- Down equilibria: $(0, 0)$
- Up equilibria: $(\pi,0)$

Classification:

- Downward equilibrium:
  - $\beta=0$: Centre
  - $\beta=1$: Stable spiral
  - $\beta=3$: Stable node

- Upright equilibrium:
  - Saddle for all values of $\beta$

The downward equilibrium is a pendulum hanging vertically down (stable). 

Whereas the upright equilibrium is a pendulum balanced vertically up (unstable).
